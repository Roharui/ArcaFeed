# UI 테스트 도구

```bash
npm run dev:ui
```

<http://127.0.0.1:4317>에서 모드, 데이터 양, 테마, 카테고리 응답 상태,
화면 크기를 선택합니다. 모든 모달 탭과 채널별 필터 편집창을 확인할 수 있습니다.
포트는 `PORT=4318 npm run dev:ui`로 바꿉니다.

`src/`, `css/`, 테스트 데이터 코드를 저장하면 Webpack이 다시 빌드하고
미리보기가 자동으로 갱신됩니다. 화면에 현재 빌드 해시와 시간이 표시됩니다.
빌드 오류는 터미널과 미리보기 아래에 전체 출력되며, 오류가 있는 번들은 제공하지 않습니다.

이 도구는 실제 모달 생성 코드와 CSS, 로컬에 설치된 의존성을 사용합니다.
계정, 사이트 접속, 유저스크립트 확장프로그램은 필요하지 않습니다.
기록과 구독 목록은 메모리의 테스트 데이터이며, 카테고리 요청은 정상·지연·실패를
재현합니다. 설정 저장, 검색, 필터 편집, 삭제와 닫기는 실제 핸들러를 실행합니다.
게시글 이동과 일괄 탐색의 네트워크·페이지 전환은 이 도구의 검사 범위에 포함되지 않습니다.
실제 사이트에 설치된 유저스크립트의 적용 여부는 `npm run dev:live`로 별도 확인합니다.

## Playwright MCP 자동 검사

서버를 실행한 다음 Playwright MCP의 `browser_navigate`로
<http://127.0.0.1:4317>을 열고, `browser_run_code_unsafe`에 아래 인자를 전달합니다.

```json
{ "filename": "scripts/check-ui.mjs" }
```

별도 Playwright 패키지나 브라우저 설치 없이 MCP의 브라우저를 사용합니다.
다른 포트를 사용했다면 해당 서버 URL을 먼저 열어 주세요.

검사 항목:

- 데스크톱·모바일·가로 화면 5종 × 모드 5종 × 데이터 양 3종 × 테마 2종
- 최초 선택한 탭만 생성되는지, 탭 선택 시 생성과 재사용, 탭 구성, 80% 높이, 본문 스크롤, 가로 넘침, 하단 버튼 잘림·간격
- 최근 본 글 검색·검색어 삭제·채널 필터·더 보기
- 탭 이동 시 스크롤 초기화, UI 설정 저장, Escape 닫기
- 이어보기 검색·삭제, 채널별 필터 편집·적용·취소
- 카테고리 요청 실패와 늦은 응답 취소

결과는 `.cache/ui-results/report.json`에 기록하고, 각 탭의 대표 화면과
실패 화면 PNG를 같은 폴더에 저장합니다. 결과의 `passed`가 `true`인지 확인하세요.
실패 시 전체 오류와 해당 시나리오의 화면 경로가 `failures`에 남습니다.
검사 전후 빌드 해시가 같아야 통과하므로 오래된 코드나 검사 도중 변경된 코드의
결과를 최신 검증으로 간주하지 않습니다. 테스트 화면의 기본 스타일은 사이트 스타일을
간략히 재현하므로 실제 사이트의 전체 스타일·확장프로그램 환경은 별도 검증이 필요합니다.

서버와 테스트 데이터의 회귀 검사는 다음 명령으로 실행합니다.

```bash
npm run test:ui:server
```

## 독립 탐색 목록 확인

미리보기의 설정창을 닫으면 고정 탐색 버튼을 사용할 수 있습니다.
모바일·PC에서 아래 동작을 확인하세요.

- `.nav-control` 요소를 화면 좌측 아래에 고정하면 탐색 버튼이 그 위로 이동하는지 확인합니다.
- 기본 내비게이션을 숨기거나 크기를 바꾸면 버튼 위치가 다시 계산되는지 확인합니다.
- PC에서는 버튼 영역에 마우스를 올렸을 때만 표시되고, 벗어나면 숨겨지는지 확인합니다.
- 모바일에서는 버튼 주변 12px 안을 터치하면 나타나고 1.5초 뒤 숨겨지는지 확인합니다. 스크롤·버튼 주변 밖의 터치·키보드 조작과 로딩만으로는 나타나지 않아야 합니다.
- 목록 첫 글·중간 글·마지막 글 및 100개 이후의 현재 글이 중앙에 표시되는지 확인합니다.
- 목록 열기·채널 필터·현재 글 표시·앞뒤 더 보기·닫기와 키보드 포커스 이동을 확인합니다.
- 실제 사이트에서 목록 직접 이동 시 탐색 조건과 순서가 유지되는지 확인합니다.

탐색 버튼 전용 자동 검사는 Playwright MCP에서
`browser_run_code_unsafe({ filename: "scripts/check-navigation-ui.mjs" })`로 실행합니다.
375px·1200px 화면에서 사이트 버튼 스타일 적용, 좌측 하단 배치, hover 유지와
hover 종료 후 숨김, 목록 첫·중간·마지막 글의 중앙 정렬을 확인합니다.

탐색 버튼 전용 검사는 목록 로딩 중 hover 시 테두리 애니메이션·목록 열기,
동시 요청의 마지막 완료 시 로딩 해제, 동작 줄이기 설정도 확인합니다.
별도 `.fetch-loader` 표시가 생성되지 않는지 검사합니다.
