# 사용 안내

## 기본 조작

| 동작                    | 방법                                                                    |
| ----------------------- | ----------------------------------------------------------------------- |
| 다음/이전 게시글        | 좌우 스와이프 또는 ← → 화살표 키                                        |
| 넓은 화면에서 글 이동   | 본문 왼쪽 빈 공간 클릭으로 이전 글, 오른쪽 빈 공간 클릭으로 다음 글     |
| 필터/UI 설정            | 우측 상단 ⚙️ 버튼                                                       |
| 스와이프 모드 켜기·끄기 | 우측 상단 🔒/▶ 버튼                                                    |
| 시리즈 활성화           | 게시글 하단 "시리즈 모드 열기" 버튼으로 새 탭 열기                      |
| 스크랩 시리즈           | 스크랩 목록에서 📁 버튼                                                 |
| 최근 본 글              | 설정의 🕘 탭                                                            |
| 이어보기                | 설정의 📖 탭                                                            |
| 구독 채널 탐색          | `/b/my` → ⚙️ → 채널별 필터 수정 → 일괄 탐색 시작                        |
| 본 글 표시              | 방문한 게시글은 목록 제목 오른쪽에 표시하며, UI 설정에서 표시 여부 변경 |
| 본 글 건너뛰기          | 게시글 제목 오른쪽 ⏭️ 버튼으로 켜기/끄기                                |

스크랩이나 구독 피드에서 읽는 글에도 시리즈가 있으면 게시글 하단의
**시리즈 모드 열기** 버튼으로 새 탭에서 해당 시리즈를 탐색할 수 있습니다.
현재 피드의 탐색 목록은 유지됩니다.

화면 폭이 1024px 이상이면 본문 좌우의 빈 공간을 클릭해 스와이프할 수 있습니다.
본문 높이 안의 여백에서만 동작하며 링크·버튼·본문 클릭과 드래그에는 적용하지 않습니다.
스와이프가 꺼져 있거나 전환 중인 경우, 설정창·탐색 목록이 열린 경우에는 동작하지 않습니다.
첫 글·마지막 글처럼 해당 방향으로 이동할 수 없으면 현재 글을 유지합니다.

필터 모달의 카테고리와 전체 선택 버튼은 테두리와 배경색으로 선택 상태를 표시합니다.
선택 시 체크 표시를 추가하지 않으므로 버튼 크기와 위치가 유지됩니다.
인기글만 보기를 켜도 카테고리·제목 필터에서 제외한 게시글은 화면 목록에서 흐리게 표시합니다.
인기글만 보기에서는 조회한 인기글 목록에 포함되지 않은 글도 흐리게 표시하고,
목록 조회가 끝나면 불투명도를 다시 갱신합니다.

좌우 스와이프 중에는 본문의 HTML 영상을 일시정지합니다. 전환을 취소해 현재 글로
돌아오면 재생 중이던 영상만 다시 재생하고, 다른 글로 이동하면 정지 상태를 유지합니다.
브라우저가 자동 재생을 제한하면 재생 버튼을 다시 눌러야 합니다. 외부 iframe 플레이어는
이 제어의 대상이 아닙니다.

화면 설정의 **조작 도움말·키보드**에서 현재 페이지의 단축키를 확인할 수 있습니다.
설정창과 탐색 대화상자는 Tab·Shift+Tab으로 내부 요소를 순환하고 Escape로 닫으며,
닫은 뒤에는 이전 포커스로 돌아갑니다. 이름 편집 중 Escape는 편집만 취소합니다.
입력 요소·편집 영역·한글 조합·키 반복·수정키 사용 중에는 글 이동 단축키를 실행하지 않습니다.
기기의 동작 줄이기 설정에 따라 Swiper 전환과 대화상자 애니메이션을 줄입니다.

## 제목 포함 필터

채널 필터의 **제목 포함 키워드**에 키워드를 쉼표로 구분해 입력합니다.
**하나 이상 일치** 또는 **모두 일치**를 선택하고 대소문자 구분을 켤 수 있습니다.
비우면 포함 조건을 적용하지 않으며, 차단 키워드와 겹치면 차단을 우선합니다.
일반 채널·하이브리드 목록·구독 피드에 같은 조건을 적용합니다.
구독 피드는 포함 조건이 있으면 최대 10페이지 안에서 첫 유효한 글 묶음을 찾습니다.

## 최근 본 글과 건너뛰기

최근 본 글과 본 글 판정은 아카라이브의 [최근 읽은글](https://arca.live/u/recents)과
같은 브라우저 기록을 사용하며, 아카피드가 방문 기록을 따로 저장하지 않습니다.
최근 본 글 탭의 목록과 검색은 방문 시각 기준 최신 300개로 제한합니다.
사이트 원본 기록과 본 글 표시·건너뛰기 판정은 이 표시 제한의 영향을 받지 않습니다.
사이트에서 기록 사용을 끄면 본 글 목록도 비워집니다. 건너뛰기는 다음 글 이동에만
적용되므로 이전 글로 돌아가거나 목록에서 본 글을 직접 여는 것은 가능합니다.
구독 피드와 구독 채널 일괄 탐색에서는 본 글 건너뛰기를 사용할 수 있으며, 같은 피드 설정을 공유합니다.
일반 시리즈 모드와 스크랩 모드에서는 본 글 건너뛰기가 비활성화되어 방문한 글도 순서대로
이동합니다. 일반 채널·피드로 돌아오면 해당 채널·피드에 저장된 설정을 다시 사용합니다.

일반 시리즈와 스크랩 모드는 현재 글 위치와 관계없이 전체 링크를 유지합니다.
일반 채널과 구독 피드는 장시간 탐색 시 지나온 링크가 200개를 넘으면 최근 100개만 유지합니다.
정리된 오래된 글까지 이전 글 버튼으로 돌아갈 수는 없지만, 아직 이동하지 않은
글은 유지됩니다. 구독 시리즈는 채널별 목록 보충에 필요한 링크도 일부 남깁니다.
최근 본 글을 건너뛰어 이동하면 다음 글에서 건너뛴 개수를 토스트로 한 번 표시합니다.
구독 피드의 `/b/my/글번호` 주소가 실제 채널 주소로 바뀌어도 같은 글의 알림을 표시합니다.
알림은 이동 주소의 임시 값으로도 전달하므로 사이트가 세션 저장소를 비워도 표시합니다.
임시 값은 초기화 전에 주소에서 제거하며 검색 조건이나 이어보기에는 저장하지 않습니다.
다음 게시글 검색에 실패해도 이동 가능한 다음 글이 1개 이상 남아 있으면 실패 토스트를
표시하지 않습니다. 이후 글이 모두 최근 본 글이면 현재 화면에서 토스트로 안내합니다.
게시글 제목 오른쪽 이모지를 누르면 본 글 건너뛰기가 꺼짐(📖)과 켜짐(⏭️) 사이에서
전환됩니다. 이모지는 제목 영역의 세로 중앙에 정렬되며 버튼 배경이나 테두리가 없고
제목 영역 높이를 늘리지 않습니다. 일반 시리즈·스크랩 모드에서는 이 버튼을 생성하지 않습니다.

## 구독 채널 일괄 탐색

구독 채널 설정에서는 채널마다 카테고리, 제목 포함·차단 키워드, 인기글 여부를 수정할 수 있습니다.
**저장**은 설정만 저장하고, **일괄 탐색 시작**은 선택한 채널의 필터를 적용해 최신 글부터
함께 탐색합니다. 필터 편집에서 적용한 뒤 바깥 설정창을 취소하면 변경을 저장하지 않습니다.

일부 채널 조회에 실패해도 성공한 채널의 글로 탐색을 시작합니다.
구독 설정과 탐색 목록에서 실패 채널·원인을 확인하고 채널별로 재시도할 수 있습니다.
모두 실패하거나 탐색할 글이 없으면 설정창에서 결과를 확인하고 다시 시도합니다.
자동 보충은 실패 채널을 제외하며, 재시도에 성공하면 해당 채널을 다시 포함합니다.
보충·재시도는 현재 글까지의 순서를 유지하고 뒤쪽 목록에 새 글을 중복 없이 합칩니다.
적용한 채널·필터 설정은 조회에 실패하거나 결과가 없어도 유지합니다.
설정 저장 자체에 실패하면 조회와 이동을 진행하지 않습니다.

## 기록 검색

최근 본 글과 이어보기 탭에서 제목·채널 이름을 검색할 수 있습니다.
이어보기는 시리즈 이름과 직접 지정한 이름도 검색하며, 여러 검색어를 띄어 쓰면 모두 포함된 기록을 찾습니다.
검색어는 검색창 오른쪽 × 버튼으로 지울 수 있습니다.

## 이어보기와 기록 관리

이어보기는 현재 브라우저에 최대 20개 탐색 위치를 저장합니다.
탐색 위치별 최대 2,000개, 전체 최대 5,000개 링크를 보관합니다.
고정 항목을 우선 보관하며, 같은 고정 상태에서는 최근 탐색 순으로 표시합니다.
오래된 탐색도 마지막 글은 유지합니다. 고정 항목에도 링크 한도에 따른 목록 축소는 적용됩니다.
20개가 모두 고정되어 있으면 새 이어보기를 저장하지 않고 안내합니다.
고정을 해제하거나 항목을 정리하면 새 탐색을 저장할 수 있습니다.
스크롤 위치는 목록과 별도로 저장하며, 이미지 로딩 후에도 최대 5초 동안
복원을 시도하고, 직접 스크롤하거나 화면을 터치하면 위치 보정을 멈춥니다.
방문 기록은 최근 본 글 탭의 **사이트 기록 관리**에서 관리하고, 이어보기 위치는
이어보기 탭의 휴지통 버튼으로 따로 삭제할 수 있습니다. 삭제 후 포커스는 목록으로 이동합니다.

연필 버튼으로 이어보기 이름을 최대 100자까지 편집합니다.
Enter 또는 저장 버튼으로 저장하고, 취소 버튼이나 Escape로 편집을 취소합니다.
빈 이름을 저장하면 기본 이름을 사용합니다. 핀 버튼으로 고정하거나 해제합니다.
자동 위치 저장은 지정한 이름과 고정 상태를 유지합니다.

## 탐색 목록과 현재 위치

채널 목록과 게시글 페이지의 좌측 하단에 탐색 버튼 하나를 표시합니다.
홈·구독 피드 홈·스크랩 목록에서는 표시하지 않습니다. 기본 위치는 왼쪽 16px, 아래쪽 20px이며,
기기 안전 영역 보정은 적용하지 않습니다. 아카라이브 `.nav-control`의 모양만
가져오며, 사이트 내비게이션 클래스는 사용하지 않습니다. 모서리 반경은 10px입니다.
버튼 높이는 기본 내비게이션의
표시 여부와 관계없이 44px로 고정합니다. 배경은 반투명 회색, 아이콘과 숫자는 흰색으로 표시합니다.
기본 내비게이션과 겹치면 그 위로 이동합니다.
탐색 버튼은 버튼 영역에 마우스를 올린 동안에만 표시되고, 벗어나면 서서히 숨겨집니다.
모바일에서는 버튼 영역과 그 주변 12px 안을 터치하면 표시되고, 1.5초 뒤 숨겨집니다.
스크롤·버튼 주변 밖의 터치·키보드 조작으로는 나타나지 않습니다.
게시글 목록을 불러오는 동안에는 바깥 테두리에 회전 애니메이션을 표시하지만,
로딩만으로 버튼을 강제 노출하지는 않습니다. 동시에 진행 중인 목록 로딩이 모두 끝나면 애니메이션을 멈춥니다.
불러올 목록이 없으면 버튼은 숨김 상태를 유지할 수 있습니다.
현재 글의 순번과 불러온 글 수를 확인하고, 버튼을 눌러 설정창과 별개로
탐색 목록을 열 수 있습니다. 순번과 개수는 불러온 목록 기준이며,
추가 로딩이나 오래된 목록 정리로 바뀔 수 있습니다.

목록은 시리즈와 스크랩의 탐색 순서를 그대로 표시하며, 구독 피드는
채널 선택으로 좁혀볼 수 있습니다. 알려진 제목은 방문 기록에서 가져오고
나머지는 채널과 게시글 ID로 표시하므로 목록을 열기 위한 본문 요청은 없습니다.
각 항목의 번호는 표시하지 않습니다. 일반 채널과 단일 채널 시리즈는 제목만 표시하고
채널 필터를 제공하지 않습니다. 구독 피드와 여러 채널의 글이 있는 목록은
채널명과 제목을 별도 줄로 표시하고 채널 필터를 제공합니다.
목록을 열면 현재 게시글이 목록 중앙에 표시됩니다.
긴 목록은 현재 글 주변부터 최대 100개씩 표시하고 ‘이전 목록 더 보기’와 ‘더 보기’로 추가합니다.
추가 로딩 버튼은 목록 위·아래에 화살표와 점선 테두리로 구분해 표시합니다.
원하는 글을 누르면 현재 탐색 조건을 유지한 채 이동합니다. 현재 글에는 ‘현재 글’을 표시합니다.
바깥 영역이나 닫기 버튼, Escape로 닫을 수 있습니다.

## 저장·이동 실패 안내

저장에 실패하면 안내하고 페이지 이동을 중단합니다. 이동 호출에 실패하면 이전 탐색 상태와
위치를 복구해 재시도할 수 있게 합니다. 이어보기·스크랩 진입에도 같은 복구를 적용하며,
시리즈 새 탭 진입에 실패하면 준비한 빈 탭을 닫습니다.
브라우저 뒤로 가기로 페이지가 복원되면 다시 글을 이동할 수 있습니다.
쿼리나 fragment가 붙은 사이트 루트 URL도 홈 화면으로 인식합니다.
