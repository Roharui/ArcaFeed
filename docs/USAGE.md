# 사용 안내

## 게시판과 게시글 탐색

루리웹 게시판에서 왼쪽으로 밀면 탐색 목록의 첫 글을 엽니다. 게시글에서는 왼쪽으로 밀어 다음 글, 오른쪽으로 밀어 이전 글로 이동합니다. 데스크톱에서는 방향키를 사용할 수 있습니다. 게시판 상단의 **스와이프 전환**으로 해당 게시판의 스와이프를 켜거나 끌 수 있습니다.

게시글의 탐색 버튼을 누르면 현재 탐색 목록에서 글을 선택할 수 있습니다. 게시판의 카테고리와 검색 조건은 탐색 목록에 반영됩니다.

## 필터

**루리피드 설정 → 필터**에서 제목 키워드를 지정합니다. 베스트 옵션을 켜면 루리웹의 베스트 목록을 조회합니다. 제목 포함과 차단 조건이 함께 적용되면 차단이 우선합니다.

## 최근 본 글

RuliFeed는 탐색한 게시글을 브라우저에 기록합니다. **최근 본 글** 탭에서 기록을 검색할 수 있고, 게시글 제목 옆의 버튼으로 본 글 건너뛰기를 전환할 수 있습니다.

모바일과 데스크톱 주소는 브라우저에서 서로 다른 출처이므로 설정과 읽기 기록이 주소별로 저장됩니다.
